# Facilitator guide — CRAFT: The Prompt Lab (online)

**Goal:** every participant builds one complete prompt using all five CRAFT parts (Context, Role, Action, Format, Tone) by themselves.
**Format:** individual, at their own pace. Original classroom version: ~7 minutes. Online version: **12–15 minutes of play** + 5–7 minutes debrief.

## Before the session (5 min)
- Open the link → Trainer Dashboard (PIN 2026). Create one session per group (use **+ New session**; name them "Group A", …).
- Share the **player link** (or the 5-character code) in the chat. Arabic link available.
- Tell participants: sound is optional (🔊 button), the game works on phone, and **no real customer or employee data** goes into prompts.

## Run (timing)
| Time | What you do |
|---|---|
| 0:00 | Say: “You just learned CRAFT. Now repair the Prompt Engine — on your own.” Share link/code. |
| 0:02 | Everyone is in. Open **Projector view** if you share your screen. |
| 0:02–0:15 | Watch the table: Stage column + C-R-A-F-T lights. Click ⌄ on a row to read someone's prompt. |
| ~0:12 | When most are done, press **Reveal leaderboard** (players see it automatically; or use Projector view). |
| 0:15–0:22 | Debrief (below). |

If someone is stuck, ask: **“What would you tell a new employee doing this task for you?”** — it unlocks Context and Role.
Hints cost coins on purpose: it makes people think first. Final challenge has no step-by-step help (one paid CRAFT cheat sheet).

## What the game does (so you can narrate it)
1. **Malfunction** — the weak prompt “Tell my team the meeting changed.” gives a useless (simulated) answer.
2. **Five modules** — Context = pick the 4 facts that belong (and spot the private data trap); Role = audition voices; Action = build the command; Format = design the output blueprint; Tone = mix formality and warmth.
3. **Assemble** — they edit the real prompt; the engine lights up as each part is detected.
4. **Simulation** — a pre-written demonstration (clearly labelled) + Copy Prompt to try ChatGPT / Copilot / Gemini if allowed at your company.
5. **Final challenge** — a new scenario, written alone; rule-based checks give transparent feedback. Optional bonus: use a real task from their own job (made-up names).
6. **Mission complete** — score, mastery feedback, first vs final prompt, copy button, reflection.

## Debrief questions
1. **Which CRAFT part was hardest to write? Why?** (Use *CRAFT coverage* on the dashboard: the lowest gold bar is the part the group struggled with in the final challenge.)
2. **How is this prompt different from what you normally type into AI?**
3. What changed between your first prompt and your final prompt? (Ask 2–3 volunteers to read ONE part of their final prompt aloud, or their reflection.)
4. Which part do you personally forget most often? What will you do about it?
5. Where would a prompt like this save you time in your own work? What data must you never put in it?

## Notes
- The automatic checks are simple keyword rules. Use them for feedback, not for grading people.
- If the live connection drops: **Refresh** on the dashboard rebuilds from the relay history; otherwise collect the backup files and use *Import*.
- Export CSV at the end (per session) if you want to keep results.
